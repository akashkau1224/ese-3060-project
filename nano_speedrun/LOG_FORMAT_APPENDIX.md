# Appendix: Log File Format Explanation

This document describes the format of different log files in the `logs/` directory. Log files are organized into different categories based on their purpose and location.

---

## Root Log Files (`logs/`)

These log files are located directly in the `logs/` directory and are used for testing and exploration.


### `inital_testing.txt`

Initial expansion factor testing log (without function values). Tested to see the feasability of the idea by testing with 3.5 and 4.0 expansion factors at first. Additionally tested with extreme expansion factors. Not listed here but using one L40 GPU any expansion factor above 7 resulted in an out of memory error. This log file was generated using the `train_gpt_initial.py`

#### Structure:
2. **Testing Section**:
   ```
   Test with expansion factor {factor} completed: final_val_loss={loss}, training_time={time}ms
   ```

**Example:**
```
Test with expansion factor 1.5 completed: final_val_loss=6.8175, training_time=202753ms
Test with expansion factor 2.0 completed: final_val_loss=6.7735, training_time=214992ms
```

**Field Descriptions:**
- **expansion factor**: MLP expansion factor tested (float)
- **final_val_loss**: Final validation loss after training (float, 4 decimal places)
- **training_time**: Total training time in milliseconds (integer)

### `function_testing.txt` and `function_testing_second.txt`

These logs contain expansion factor testing with custom function evaluation to factor in training time and validation loss into one metric (w(loss) + (1-w)(training_time) with w=0.96). This log file was generated by running `train_gpt_function.py`
1. **Testing Section**:
   ```
   ==============================================
   Testing expansion factors
   ==============================================
   Test with expansion factor {factor} completed: final_val_loss={loss}, training_time={time}ms
   Function value for expansion factor {factor}: {value}
   ```

**Example:**
```
Test with expansion factor 3.0 completed: final_val_loss=6.7356, training_time=242236ms
Function value for expansion factor 3.0: 2.2746
Test with expansion factor 3.1 completed: final_val_loss=6.7335, training_time=244867ms
Function value for expansion factor 3.1: 2.2746
```

**Field Descriptions:**
- **expansion factor**: MLP expansion factor tested (float)
- **final_val_loss**: Final validation loss after training (float, 4 decimal places)
- **training_time**: Total training time in milliseconds (integer)
- **Function value**: Custom metric combining validation loss and training time

### `long_testing.txt`

Extended testing log with longer training runs. Logged the previous function value periodically to show the trend over time of the validation loss, training time and the function value. This file was generated by running `train_gpt_longer.py`

#### Structure:
Similar to `inital_testing.txt`, but with longer training iterations and potentially different expansion factors.

**Example:**
```
Test with expansion factor 3.1 completed: final_val_loss=4.2686, training_time=1099112ms
```

## Individual Exploratory Runs (`logs/individual_exploratory_runs/`)

These logs contain exploratory training runs used for hyperparameter search and experimentation. Files are named with UUIDs (e.g., `2c103f6e-168b-4cd6-8ab3-2130af9d5cf9.txt`). They were run using the `train_gpt_longer.py` script and the final results for these individual runs are in the long_testing.txt log file.

### Structure:

Similar to individual final runs, but with additional final results summary:

#### 1. Code Section
```
====================================================================================================
[Full Python training script code]
====================================================================================================
```

#### 2. Environment Information Section
```
Script running on seed: 42
Running pytorch 2.8.0+cu128 compiled for CUDA 12.8
nvidia-smi:
[Full nvidia-smi output]
====================================================================================================
```

#### 3. Training Logs Section

Same format as individual final runs:
- Training step format: `step:{step}/{num_iterations} train_loss:{train_loss:.4f} train_time:{time_ms:.0f}ms step_avg:{avg_time:.2f}ms`
- Validation step format: `step:{step}/{num_iterations} val_loss:{val_loss:.4f} train_time:{time_ms:.0f}ms step_avg:{avg_time:.2f}ms`

#### 4. Final Results Summary

At the end of each exploratory run, there is a summary section:

```
==============================================
Final Results for run_id: {run_id}, expansion_factor: {factor}, final_val_loss: {loss}, training_time_ms: {time}, peak_memory_mib: {memory}
==============================================
```

**Example:**
```
==============================================
Final Results for run_id: 2c103f6e-168b-4cd6-8ab3-2130af9d5cf9, expansion_factor: 3.5, final_val_loss: 6.7239, training_time_ms: 249869, peak_memory_mib: 12345
==============================================
```

**Field Descriptions:**
- **run_id**: Unique identifier for the run (UUID)
- **expansion_factor**: MLP expansion factor used in this run (float)
- **final_val_loss**: Final validation loss (float)
- **training_time_ms**: Total training time in milliseconds (integer)
- **peak_memory_mib**: Peak GPU memory consumption in MiB (integer)

**Notes:**
- These runs are typically shorter (e.g., 500 iterations) for faster exploration
- Used for hyperparameter search and expansion factor testing
- May include additional intermediate validation loss logging

## Individual Final Runs (`logs/individual_final_runs/`)

These logs contain complete training runs for final model evaluation. Files are named with expansion factor and run number (e.g., `3_5_final_run_first.txt`, `4_0_final_run_second.txt`). These files are run using the `train_gpt_final.py` by changing the expansion factor field in the GPTConfig.

### Structure:

Each log file contains three main sections:

#### 1. Code Section
```
====================================================================================================
[Full Python training script code]
====================================================================================================
```
- Contains the complete training script code for reproducibility
- Allows exact recreation of the training run

#### 2. Environment Information Section
```
Script running on seed: 42
Running pytorch 2.8.0+cu128 compiled for CUDA 12.8
nvidia-smi:
[Full nvidia-smi output showing GPU information]
====================================================================================================
```
- **Seed**: Random seed used for reproducibility
- **PyTorch Version**: Version of PyTorch used
- **CUDA Version**: CUDA version PyTorch was compiled for
- **nvidia-smi**: Full GPU information including:
  - GPU model and memory
  - Driver version
  - GPU utilization and temperature

#### 3. Training Logs Section

Each line represents one training step or validation evaluation:

##### Training Step Format
```
step:{step}/{num_iterations} train_loss:{train_loss:.4f} train_time:{time_ms:.0f}ms step_avg:{avg_time:.2f}ms
```

**Example:**
```
step:1/6600 train_loss:15.9885 train_time:48391ms step_avg:nanms
step:2/6600 train_loss:9.4433 train_time:48545ms step_avg:nanms
```

**Field Descriptions:**
- **step**: Current training step number (1-indexed)
- **num_iterations**: Total number of training iterations
- **train_loss**: Training loss on the current batch (float, 4 decimal places)
- **train_time**: Cumulative training time in milliseconds (excluding first 10 steps)
- **step_avg**: Average time per step in milliseconds (may be `nan` for early steps)

##### Validation Step Format
```
step:{step}/{num_iterations} val_loss:{val_loss:.4f} train_time:{time_ms:.0f}ms step_avg:{avg_time:.2f}ms
```

**Example:**
```
step:0/6600 val_loss:15.9931 train_time:274ms step_avg:nanms
step:125/6600 val_loss:3.2456 train_time:15234ms step_avg:121.87ms
```

**Field Descriptions:**
- **step**: Current step number (0 for initial validation, then at intervals)
- **num_iterations**: Total number of training iterations
- **val_loss**: Validation loss averaged across validation batches (float, 4 decimal places)
- **train_time**: Cumulative training time in milliseconds
- **step_avg**: Average time per step in milliseconds

**Notes:**
- Validation occurs at step 0 (initial), periodically based on `val_loss_every`, and at the final step
- Training steps are 1-indexed, validation steps may be 0-indexed
- First 10 training steps are excluded from timing measurements (warmup period)
- `step_avg` will be `nan` for steps ≤ 11 due to warmup exclusion
- Log files may end with peak memory consumption information:
  ```
  peak memory consumption: {memory_mib} MiB
  ```
